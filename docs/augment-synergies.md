# 16.23 海克斯联动

这里记录双卡的实际触发关系。16.23 卡池以 [AramHex 国服目录](https://aramhex.com/data/) 核对。不同补丁的攻略和实战用于提供验证线索。浮层的胜率仍是单卡统计。

目前将 68 对双卡和 5 组三卡用于选卡浮层。鼠标点选已识别的卡片后，助手在选卡界面关闭时记录这张卡。HUD 图标可辅助确认。开发版漏记时可在设置里补勾选。候选卡凑齐组合时显示联动，三卡规则要求另外两张已经记录。同一张候选命中多条规则时，优先展示有卡面依据的组合，同等级优先展示三卡组合，其余用「+N」计数。下面的「待实测」和三卡表里的验证项目均按试用规则处理，浮层展示它们时会标记「待实测」。

| 双卡 | 目前的处理 | 依据和限制 |
| --- | --- | --- |

下列卡名与 ID 对照 [AramHex 国服目录](https://aramhex.com/data/)。机制核对参考 [26.23 卡面](https://mobalytics.gg/lol/tier-list/mayhem)。「卡面支持」表示两张卡的效果可以组成明确的打法链条，具体数值、内部冷却和触发归属仍以国服实测为准。「待实测」表示关键的一步取决于游戏如何给额外伤害、治疗或攻击特效归类。

| 双卡 | 依据 | 实际改变与验证点 |

| 虚幻武器（1029）＋火上浇油（1036） | 待实测 | 检查技能施加攻击特效时能否叠普攻灼烧。对照原生附带攻击特效的技能与普通伤害技能。 |
| 弹跳蜜蜂（3048）＋秘术冲拳（1058） | 待实测 | 测量同一次强化普攻弹到多名英雄时的总冷却变化，确认各弹是否携带秘术冲拳。 |
| 弹跳蜜蜂（3048）＋火上浇油（1036） | 待实测 | 查看弹射目标身上有没有独立灼烧，决定普攻灼烧能否从单目标扩散到多人。 |

### 急急小子与冷却类海克斯

急急小子把通用技能急速转为移速。技能专属急速的移速收益需要进局核对。冷却返还和重置类的提示描述走位与施法节奏，卡面没有提供可供转化的通用急速。依据 [16.23 海克斯卡面](https://op.gg/zh-cn/lol/modes/aram-mayhem)。

### 三卡组合

| 三卡 | 验证重点 |
| --- | --- |
| 珠光护手＋易损＋大腕 | 分别测试直接技能伤害、持续伤害和装备伤害。前两张拓宽能暴击的伤害来源，大腕是否把额外暴伤传给每一类，须逐类测量。 |
| 火上浇油＋炼狱导管＋易损 | 逐个加入海克斯，测普攻灼烧、技能灼烧的暴击和冷却返还。暴击与冷却返还是两个独立验证点。 |
| 会心治疗＋灵魄炸弹＋死亡之环 | 对多名残血队友触发一次灵魄炸弹，分别记录治疗是否暴击、有效治疗总量、环的出伤次数。 |
| 由心及物＋翻倍时间＋溢流 | 记录同一笔法力成长兑换的生命、伤害与治疗护盾增益，对照费用翻倍后的实战续航。 |
| 终极刷新＋终极唤醒＋你摸不到 | 在两次大招前后记录免疫状态和三个基础技能冷却，确认短时间内到底能重开几次输出窗口。 |

实测记录应包含补丁、英雄、技能、目标数量和触发前后的层数、伤害或冷却。涉及英雄技能和装备的交互可以单独维护，例如虚幻武器对已充能心之钢的触发。[心之钢交互](https://aramgg.com/en/augments/1029)
