# OP.GG 派生快照落地计划

**目标：** 首次启动时把可用的 OP.GG 派生海克斯静态快照写入 SQLite，让推荐离线可用，同时诚实显示英雄总榜暂缺。

**架构：** Tauri 启动时检查本地海克斯表；表为空时导入随应用打包的静态 JSON，已有用户数据不覆盖。英雄榜没有数据时，查询退回到快照中出现的英雄列表，名次和段位留空。OP.GG 当前条款禁止自动脚本抓取，当前版本不在线更新。

**约束：** 不显示胜率；S/A/B 是应用分层（每位英雄序位 1–10、11–35、其余）；快照补丁标为未核实；对局中不联网；保留 JSON 导入。
